# Low-Value Guard

AI-powered Chrome extension that predicts and filters uninterested LinkedIn posts.



https://github.com/user-attachments/assets/faeb4fe2-10c1-4a9d-8483-50411c6bed35



## Tech stack

- **Extension:** Manifest V3, Angular, TypeScript/JavaScript, Tailwind CSS.
- **API:** Python, FastAPI, Docker, Google Cloud Run.
- **ML:** TensorFlow/Keras CNN, Word2Vec, LiteRT inference.
- **Auth & data:** Firebase Authentication, Firestore, Google Cloud Storage.
- **Training:** Google Cloud Build.
